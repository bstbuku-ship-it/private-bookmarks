# Private Bookmarks（私密书签管家）

Private Bookmarks is a password-protected, locally encrypted bookmark manager for Chrome.

私密书签管家是一个带密码的私密书签库：书签不放进浏览器自带的书签里，而是整体加密后只保存在本机，只有输入密码后才能看到和打开。

## 功能

- **密码解锁**：首次使用设置一个密码，之后每次打开扩展都要输入密码才能进入；忘记密码无法找回（见下文）。
- **加密存储**：整个书签库用 AES-256-GCM 加密后才写入浏览器本地存储，磁盘上看不到任何网址；密钥由密码派生（PBKDF2-SHA256，新数据 100 万次迭代），改密码不需要重新加密整个库。
- **文件夹分类**：自建文件夹、子文件夹，支持搜索、拖拽整理、重命名和删除，文件夹内书签数量自动统计。
- **添加书签**：弹窗里可一键添加当前页面；在展开页可手动添加单个书签。
- **批量添加**：一次贴入很多链接，每行一个。只贴网址也可以，会逐个在后台标签页静默打开读取网页的真实标题（读完立即关闭，不会切换过去，谷歌表格等动态页面也能读到名字；每个网址最多等 8 秒，读不到就改用网址推导的名称）；也可以写成「名称 | 网址」指定名称，指定的名称优先，不会再打开网页；还支持 `[名称](网址)` 的写法。识别不出的行会提示，确认后忽略。在弹窗里批量添加时，会先转到展开页再读取标题（弹窗打开标签页会自己关掉）。
- **检查更新**：顶栏品牌旁边有个版本号药丸（`v1.0.0`），解锁后会静默检查 GitHub 有没有新 Release，有新版时药丸变橙色并弹出更新窗口；点药丸可以手动再查一次。更新窗口里有关闭、「暂时忽略」和「前往 GitHub 更新」，更新仍需手动下载 zip 覆盖插件文件夹。
- **文件夹一键打开全部**：在文件夹菜单或右上角「更多」菜单里，选择打开当前文件夹（含子文件夹）里的全部书签，会先显示数量请你确认，然后在后台标签页逐个打开。
- **备份与恢复**：导出加密备份（打开时需要备份当时的密码）或明文备份（仅用于迁移到别处，用完请删除）；可从备份文件合并或替换当前书签库，替换前会自动先备份当前内容。
- **自动备份**：开启后，整理书签一段时间后会自动保存一份加密备份，按星期轮换、最多保留 7 个文件；可选择放在插件所在文件夹里的「备份」子文件夹，或保存在下载文件夹。
- **解锁有效期**：可设置为立即上锁，或解锁后 1 分钟 / 5 分钟 / 1 小时内不用再输密码；设为立即上锁最安全，关掉弹窗或页面后就要重新输入密码。点右上角锁形按钮可随时手动上锁。
- **修改密码**：修改后，之前放进会话里的解锁密钥会作废，其它已打开的页面需要用新密码重新解锁；之前的备份文件仍需要用备份当时的密码打开。

## 安全与隐私

- **书签不上传、不联网同步**：书签库、密码和密钥从不发送到任何地方，不使用浏览器自带的书签接口（`chrome.bookmarks`），不上传、不同步、不统计。你的书签不会出现在浏览器自带的书签文件里，也不会被能读取浏览器书签的代码一键取走。扩展仅有的对外网络请求是：检查更新时向 GitHub API 请求公开的最新 Release 信息（只含版本号与说明，不含你的任何数据），以及批量添加读取标题时打开你自己贴的网址。
- **未解锁时是密文**：未输入密码时，扩展页面里没有任何明文书签；磁盘上的数据是加密后的密文，没有密码打不开。其它网页、其它扩展都读不到这个扩展的本地存储；扩展没有内容脚本、没有对外消息接口、没有可被网页访问的资源。
- **密码就是一切**：密码强度决定离线破解的难度。请用足够长的密码（建议 12 位以上，最好是一句自己记得住的长口令），不要用生日、手机号、常用弱密码。密码只用来在本地派生密钥，不会被发送到任何地方。
- **打开书签是正常浏览**：书签本身只接受 `http` / `https` 网址。打开后，被打开的网站会知道你访问了它，浏览器标签页里也会显示该网址——这是所有浏览器的正常行为。批量打开前请确认数量。
- **书签图标**：列表里的小图标由浏览器按网址取用，取图标的过程可能向图标服务或目标站点暴露该网址。如需最高隐私，请勿在意图标显示，或在使用后锁定扩展。

## 安装（加载已解压的扩展程序）

1. 在 GitHub Releases 里下载最新版本的 zip，解压到一个文件夹（不要删除这个文件夹，扩展要一直从这里读取）。
2. 打开 Chrome，进入 `chrome://extensions`，打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择刚才解压出的文件夹（里面有 `manifest.json`）。
4. 点工具栏的扩展图标打开「私密书签管家」，首次使用先设置密码。

更新时：解锁后如有新版会弹出更新窗口，点「前往 GitHub 更新」下载新版 zip，解压覆盖旧文件夹，然后在 `chrome://extensions` 里点「重新加载」（或先移除旧版、再加载新版；移除前请先导出一份加密备份）。仅点「重新加载」不会清空已保存的设置。顶栏的版本号药丸变橙色表示有新版，点它可以手动再查一次；点「暂时忽略」后该版本不再自动提醒，手动点药丸仍可重新看到。

## 使用

- **解锁**：输入密码点「解锁」。首次使用时，先设置密码（至少 8 位），也可以在设置密码的界面先从备份文件恢复。
- **添加**：点「添加书签」（弹窗里默认是添加当前页面），或点右上角「⋯」里的「批量添加书签…」一次贴入很多链接。
- **整理**：拖动书签或文件夹可以移动位置；点文件夹可以进入，点「所有书签」回到最外层；搜索框可按名称或网址搜索。
- **打开**：点一条书签在新标签页打开；按住 Ctrl / Cmd 点则在后台打开；Shift 点则在新窗口打开。文件夹的右键 / 更多菜单里有「打开全部书签」。
- **备份**：右上角「⋯」→「导出备份文件…」，推荐用加密备份；「自动备份」开启后会按星期轮换保存。重要备份请再复制一份到别处，不要只放在插件文件夹里（文件夹删掉，备份也会一起没了）。
- **恢复**：右上角「⋯」→「导入备份文件…」，选择备份文件后可选「合并」或「替换」。
- **上锁**：右上角「⋯」→「上锁时间」可改有效期；点锁形按钮立即上锁。

## 忘记密码怎么办

忘记密码无法找回：书签库是用密码加密的，没有密码谁也打不开，包括开发者。只能在解锁界面点「忘记密码？」重置，从空白重新开始；如果你有备份文件，重置后在设置密码的界面选「从备份恢复」，输入备份当时的密码即可找回备份里的书签。

## 常见问题

- **提示密码错误？** 请确认大小写、输入法和空格。密码区分大小写；全角/半角字符不同也会导致密码不同。
- **换了电脑 / 重装系统后书签还在吗？** 不在。书签只存在这台电脑的浏览器里，换电脑、重装系统、卸载扩展都会一起消失。请提前导出加密备份并妥善保管。
- **书签名称识别得不对？** 批量添加时，没有写名称的会打开网页读真实标题；读不到（超时、需要登录、没有标题）时才改用网址推导的名称（取网址路径里有意义的一段），个别网址只能识别出域名。点书签的「编辑」可以随时改名；也可以在批量添加时写成「名称 | 网址」指定名称。
- **版本号药丸变橙色了？** 说明 GitHub 上有了新版本。点药丸或等解锁后的提醒窗口，确认后去 Releases 下载新版；不想更新就点「暂时忽略」。
- **文件夹里有很多书签，一键打开会怎样？** 会逐个在后台标签页打开，打开前会先显示数量请你确认；数量很多时会稍慢，请耐心等待，不要重复点击。
- **备份文件夹提示需要重新授权？** 浏览器重启后，之前选的文件夹可能需要重新授权，按提示点一下即可；未授权时备份会先存到下载文件夹。
